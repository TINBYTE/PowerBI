## 📖 About
This repository is designed to provide a structured learning path for Power BI users, from beginners to advanced levels. You will find courses, hands-on exercises, and sample datasets to practice your Power BI skills.

## 📚 Course Materials
The **Course Materials** section contains:
- PDF guides and tutorials 📄
- Power BI dashboards and reports 📊
- Sample datasets for practice 📂

## 🏋️‍♂️ Exercises
The **Exercises** section includes:
- Hands-on Power BI exercises ✅
- Real-world business scenarios 🌍
- Solutions to the exercises 📝

## 🛠 Installation Guide
To use the materials in this repository, follow these steps:
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/).
2. Clone this repository using:
   ```sh
   git clone https://github.com/your-username/PowerBi.git
   ```
3. Open Power BI and start practicing!

## 🚀 How to Use
1. Navigate to the **Course Materials** folder to start learning.
2. Try solving exercises .
3. Check solutions and compare with your approach.
